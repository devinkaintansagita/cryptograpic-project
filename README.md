# cryptograpic-project
Cryptography Implementation Using C++

# About the Project
This project implements a combination of cryptographic algorithms using C++ for key and message encryption and decryption. The system applies different cryptographic techniques to the encryption and decryption of keys and messages. The implemented techniques include:
- Modified Key Plaintext/Ciphertext
- Vigenère Cipher
- Caesar Cipher
- XOR Cipher
- Data Encryption Standard (DES)
- Base64 Encoding
The project demonstrates how multiple cryptographic techniques can be combined into a sequential encryption and decryption process.

# Objectives
The objectives of this project are:
- To implement multiple cryptographic algorithms using C++.
- To understand the application of classical and symmetric cryptography.
- To implement a multi-layer encryption process for keys and messages.
- To understand the relationship between encryption and decryption processes.
- To implement key processing and message protection using different cryptographic techniques.

# Cryptographic Techniques
1. Modified Key Plaintext/Ciphertext
A modification process is applied to the key plaintext during key encryption and to the key ciphertext during key decryption. This process is used as part of the key transformation before or after applying the Vigenère Cipher.

2. Vigenère Cipher
The Vigenère Cipher is a classical substitution cipher that uses a key to perform character-based encryption and decryption. In this project, Vigenère Cipher is applied as part of the key encryption and decryption process.

3. Caesar Cipher
The Caesar Cipher is a substitution cipher that shifts characters by a fixed number of positions. In this project, it is used in the message encryption and decryption process.

4. XOR Cipher
The XOR Cipher applies the XOR logical operation between the message and a key. XOR is used as one of the layers in the message encryption and decryption process.

5. Data Encryption Standard (DES)
DES is a symmetric-key block cipher that uses a secret key for encryption and decryption. In this project, DES is applied to both the key encryption/decryption process and the message encryption/decryption process.

6. Base64
Base64 is an encoding technique used to represent binary data using printable characters. In this project, Base64 is applied during the message encryption process and reversed during message decryption.
